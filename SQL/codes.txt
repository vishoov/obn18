When to use which 

1. all the rows are meaningful
2. when you want all the data, duplicacy removal doesnt matter
3. we know duplicates cannot occur
4. PErformance requirement (UNION takes more time)

INTERSECT

-> it returns only those rows that appear in both the query results.
its the equivalent of finding common part of two sets 

When to use :

1. when a single user is taking multiple services 
2. based on multiple requirements 

EXCEPT

returns rows from first query that do not occur in the second query. 

Order matter -> first results minus second reslts

FROM Mern

EXCEPT

SELECT student_id, student_name 
FROM Data
